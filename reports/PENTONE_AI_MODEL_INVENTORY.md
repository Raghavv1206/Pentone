## 1. Executive Summary

This inventory documents **every AI model, AI API, browser-native AI API, speech model, language model, embedding model, and inference runtime** present in the Pentone codebase.

A critical finding of this audit is that **Pentone does NOT use a single unified AI model for all tasks**. Instead, Pentone employs a **hybrid, tiered local-first architecture**:
1. **Audio & Voice Processing:** Uses specialized local ONNX models via WebAssembly (`Whisper`, `Silero VAD`, `CAM++`) and browser APIs (`Web Speech Recognition`, `SpeechSynthesis`).
2. **Text Embeddings & Semantic Search:** Uses a local Transformer model (`Xenova/all-MiniLM-L6-v2`) running on ONNX WASM.
3. **High-Level Conversational Reasoning & Tool Orchestration:** Uses Google Chrome's Built-in AI **Prompt API** (`window.LanguageModel`, backed by Gemini Nano / Gemma).
4. **Specialized In-Page Tasks:** Calls specialized experimental Chrome Built-in AI APIs (`window.Summarizer`, `window.Writer`, `window.Rewriter`, `window.Translator`, `window.LanguageDetector`).
5. **Noise Reduction:** Uses a deterministic classical **DSP Wiener filter** (`NeuralNoiseReductionService`) that contains **zero neural weights**.

## 3. Key Architectural Findings from Inventory

1. **The Core LLM is Google Chrome's Prompt API:**
   Normal conversational understanding, agent planning, and tool calling are powered exclusively by `window.LanguageModel` (Chrome Built-in AI / Gemini Nano). There is no OpenAI, Anthropic, or external cloud LLM in Pentone.
2. **Local Embedding Engine Exists via Transformers.js:**
   Pentone already bundles and executes `@xenova/transformers` (`all-MiniLM-L6-v2`) locally via ONNX WebAssembly. This model runs 100% on-device for vector search.
3. **Local ASR Exists via Transformers.js:**
   Pentone already bundles and runs `Xenova/whisper-tiny.en` on-device via ONNX WebAssembly for speech transcription.
4. **Local Biometrics & VAD are Zero-Download Assets:**
   Both `Silero VAD` (`assets/silero_vad_*.onnx`) and `CAM++` (`assets/cam_speaker.onnx`) are shipped directly inside Pentone's `assets/` directory. They never require network downloads.
5. **Summarization Unnecessarily Relies on a Separate API:**
   `summarizePage` explicitly probes `window.Summarizer` (a separate experimental Chrome API) before falling back to `window.LanguageModel`. In Chrome for Testing, both fail because Gemini Nano weights cannot be downloaded via Omaha ComponentUpdater.
